# Редактирование сайта через CMS

Короткий гайд для Ленара (T-Tech). Через CMS вы сами правите цены, описания услуг, кейсы и программы 1С — без редактора кода и без обращений к разработчику. После сохранения изменения автоматически уходят на сайт за ~30 секунд.

---

## 1. Как зайти в CMS

**Адрес:** https://ilshatsharapov69-afk.github.io/tattech-website/admin/

Откройте ссылку — увидите экран входа Sveltia CMS. Дальше есть **два способа** входа.

### Способ A — Sign In with Token (Personal Access Token)

Самый простой: один раз получаете токен в GitHub, вставляете — браузер запоминает.

1. Зайдите на https://github.com/settings/tokens?type=beta (нужен GitHub-аккаунт; если его нет — попросите Ильшата создать корпоративный с доступом только к одному репозиторию).
2. Нажмите **Generate new token** → **Fine-grained token**.
3. **Token name:** `tattech-cms`. **Expiration:** 1 год (можно продлить).
4. **Repository access** → **Only select repositories** → выберите `ilshatsharapov69-afk/tattech-website`.
5. **Repository permissions** → найдите **Contents** → выберите **Read and write**. Остальное — Read-only по умолчанию.
6. Внизу нажмите **Generate token** → скопируйте получившийся токен (`github_pat_...`). **Сохраните его в надёжное место — больше его GitHub не покажет.**
7. На экране CMS нажмите **Sign In with Token** → вставьте токен → **Sign In**.

Браузер запомнит токен. Следующий вход — сразу без вопросов (если не чистите cookies).

### Способ B — Sign In with GitHub (после деплоя OAuth-прокси)

Если Ильшат развернёт Cloudflare Worker (см. `DEPLOY-CMS.md`), появится кнопка **Sign In with GitHub** — обычный OAuth-логин в один клик. Токен не нужен.

## 2. Что можно редактировать

В левой колонке три раздела:

### 📄 Услуги (8 страниц)

Это страницы `/uslugi/[название]` — например `/1s-razrabotka`, `/obsluzhivanie-1s`, `/1s-its-prof`.

Для каждой можно править:
- **Заголовок Hero** — большой H1 в шапке
- **Подзаголовок Hero** — текст под H1
- **Бейджи** (до 4 штук) — маленькие плашки под подзаголовком
- **Что входит** (3-6 пунктов) — основной список ценности
- **Прайс-таблица** — тарифы (название/цена/примечание/основной)
- **FAQ** (3-6 вопросов) — внизу страницы
- **SEO Title** и **SEO Description** — для Google
- **Похожие услуги** — slug'и (например `obsluzhivanie-1s`) для блока «Похожие услуги» внизу

**⚠ НЕ менять:**
- **Slug (URL)** — это адрес страницы. Менять только если меняете URL целиком (потеряете SEO).
- **Иконка** — название из библиотеки (code, settings, shield и т.д.). Менять только согласовав с Ильшатом.
- **Подсветка для ИТС-страниц** — техническое поле для тарифной подсветки.

### 📊 Кейсы

Один список из 8 кейсов (отображается на главной + на /nashi-kejsi).

Поля кейса:
- **Отрасль** (например «ЖКХ»)
- **Проблема клиента** — что было до внедрения
- **Что внедрили** — конфигурация 1С
- **Метрика результата** — числовой эффект
- **Срок** — за сколько внедрили
- **Цвет заголовка** — HEX (#1D4ED8)

**⚠ Имя файла-картинки** — менять только если есть готовая картинка в `public/images/cases/` с правильным именем (формат `01-zhkh-960.webp`). Иначе картинка перестанет показываться.

### 🛒 Программы 1С

Один список из 5 программ (главная + /programmy-1s).

Поля программы:
- **Эмодзи** (📊, 🛒, 📁, 🏪, 👥)
- **Название** (1С:Бухгалтерия и т.д.)
- **Цена** (например «от 4 000 ₽»)
- **Под ценой** (примечание мелким шрифтом)
- **Описание** (1 предложение)
- **Bullets** (3 пункта, плюс-фишки)
- **Текст для Telegram CTA** (что подставится в `text=` при переходе в TG)

## 3. Как сохранить и опубликовать

1. После правок нажмите кнопку **Save** в правом верхнем углу.
2. CMS закоммитит изменения в GitHub.
3. GitHub Actions автоматически запустит сборку и публикацию (~30 секунд).
4. Через **30-60 секунд** изменения видны на сайте.

**Можно проверить статус публикации** на https://github.com/ilshatsharapov69-afk/tattech-website/actions — последний коммит должен иметь зелёную галочку.

## 4. Частые вопросы

**Q: Я случайно поменял что-то лишнее. Можно отменить?**
A: Да. Откройте https://github.com/ilshatsharapov69-afk/tattech-website/commits/main, найдите коммит с вашим изменением, нажмите «Revert» — изменения откатятся через 30 секунд.

**Q: Цена в Услуге не показывается / пропала.**
A: Проверьте, что в «Прайс-таблица» хотя бы один тариф есть, и поле **Цена** заполнено. Если оставить пустым — блок прайса исчезнет.

**Q: Я меняю SEO-Title — это безопасно?**
A: Да. Title виден только в Google. Меняйте на более точную/привлекательную формулировку — главное, до 60 символов.

**Q: Можно загрузить новую картинку для кейса?**
A: Пока — нет (требует отдельной настройки media). Передайте Ильшату картинку, он добавит и обновит «Имя файла-картинки» в CMS.

**Q: Я ввёл цену со значком ₽ — нормально?**
A: Да. Просто пишите как видите на сайте: «от 4 000 ₽», «48 500 ₽».

**Q: Сайт упал после моего изменения!**
A: Маловероятно, но если такое — напишите Ильшату с описанием что меняли. Откатить — через GitHub commits/revert (см. вопрос 1).
